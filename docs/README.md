# WPF Controls
**Tudormobile.WpfControls** contains a collection of controls for use in developing user interfaces for Windows desktop applications utilizing the WPF framework.  

[Source Code](https://github.com/tudormobile/WpfControls) | [Documentation](https://tudormobile.github.io/WpfControls/) | [API documentation](https://tudormobile.github.io/WpfControls/api/Tudormobile.html)
## Getting Started
### Install the package
```
dotnet add package Tudormobile.WpfControls
```
### Prerequisites
**NONE**

### Dependencies
**NONE**
